# macros

Earlier VBA approach, kept for reference. It shows what the SolidWorks API can do from inside the application, and where the manual steps begin. The maintained path is the C# runner in `../runner`.

| File | Purpose |
|---|---|
| `QuizSolidWorksAutomation.bas` | Writes Equation Manager values and creates named geometry for a profile. |
| `HelicalGearMacro.bas` | Builds gear blank, bore, keyway and reference geometry; stops before the tooth profile. |

Each macro has its own README next to it. Both use placeholder student data. A SolidWorks runtime test is still required before relying on either.
